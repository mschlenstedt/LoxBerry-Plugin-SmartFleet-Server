# SmartFleet Server – LoxBerry-Plugin

Installiert den SmartFleet-Server auf einem LoxBerry: MariaDB, das signierte
Serverpaket, einen eigenen HTTPS-Port ab 9000 mit selbst signiertem
Zertifikat und die Ersteinrichtung mit einer Free-Lizenz.

**Nur für interne Tests, nicht für den Dauerbetrieb.** Für den Betrieb gehört
der SmartFleet-Server auf ein Webhosting mit eigenem Zertifikat.

Voraussetzung: Der Mailversand des LoxBerry ist eingerichtet (LoxBerry >
Mailserver). Ohne ihn bricht die Installation ab, denn den ersten Zugang legt
SmartFleet erst nach einer Testmail an.

Handbuch: https://smartfleetmanager.de/docs/
